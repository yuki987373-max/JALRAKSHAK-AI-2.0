# Map provider setup

JalRakshak uses MapLibre GL JS with OpenFreeMap vector tiles as an optional live basemap. No Google Maps API key or paid mapping account is required. Live map tiles need an internet connection and may occasionally be unavailable.

The map is for navigation and visible-feature inspection. Public vector maps can be incomplete; this edition does not connect to QGIS or read GeoPackage files. Optional offline GeoJSON imports are handled in the browser.

The main 3D digital-twin demo is independent of the map and runs without GIS data. It is a schematic illustration rather than a surveyed real-world model.
